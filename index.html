Credit default prediction · submission documents

Model methodology and experiment results

The final prediction is a weighted average of three models, each using a different view of the same customer data. This site explains the methodology and records all 41 experiments.

Results

The submitted model combines three probabilities using a fixed weighted average. It does not use a meta-model or calibration, and the only post-processing is probability clipping.

Solo scores are out-of-fold log loss on 24,000 labelled customers.
ComponentWeightSolo OOF
LightGBM0.450.42211
GRU0.300.42392
TabPFN0.250.42345
Blended, out-of-foldweighted average of probabilities 1.000.42136
Hidden test6,000 rows, binary log loss 0.40982

How to read the blended score. The model averages each customer’s predicted probabilities, then calculates log loss on the combined predictions. For this reason, weighting the three individual scores above will not produce 0.42136.

The final ensemble contains three of the ten model families tested and uses 81 engineered features organised into six families. Seven candidate feature additions were also tested, of which one was retained. Each prediction combines 281 fitted models: 270 cross-validated fold fits across six fold partitions and 11 refits on all 24,000 rows.

Disclosure

  • Pretrained model usedTabPFN (Prior Labs), accessed through the tabpfn package. It requires a licence and API token, performs in-context learning and fits no parameters to this dataset.
  • AI coding agent usedClaude Code was used throughout the project.
  • External solutions consultedThe first-, second- and third-place reports from the AMEX Default Prediction competition. Five techniques were tested: DART boosting, high min_data_in_leaf, feature_fraction_bynode, recency-window aggregates and within-customer ranks. None improved cross-validation and none were adopted. Detailed results are available in the experiment ledger.
  • External datasets usedNone. Only the competition-provided files.
  • Manual modification of predictionsNone beyond clipping to [1e-4, 1−1e-4].

Reproduction

Saved prediction vectors and instructions for reproducing each component are in artifacts/. The submitted file is submissions/submission_tabpfn6.csv. A full retraining run takes several hours, primarily because of the 150 GRU fits and TabPFN’s context-length scaling.

Ensemble: 0.45 × LightGBM (81 features, 90 fits + full-data refit) + 0.30 × bidirectional GRU (6×8 panel, 150 fits + refit) + 0.25 × TabPFN (30 fits + refit, pretrained). Fixed seeds; six stratified 5-fold partitions; probabilities clipped to [1e-4, 1−1e-4] and otherwise unmodified. Out-of-fold log loss 0.42136 on 24,000 customers; 0.40982 on the 6,000-row hidden test set.
