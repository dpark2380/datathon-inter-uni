How the model works, and everything we tried to get there

A weighted average of three models that read the same customers in three different ways. Each earned its place by measurement; thirty-seven other candidates did not.

The result

The submitted model is a plain weighted average of three probabilities. No meta-model, no calibration, no post-processing beyond clipping. Its accounts read as follows.

Solo scores are out-of-fold log loss on 24,000 labelled customers.
ComponentWeightSolo OOF
LightGBM0.450.42211
GRU0.300.42392
TabPFN0.250.42345
Blended, out-of-foldweighted average of probabilities 1.000.42136
Hidden test6,000 rows, binary log loss 0.40982

Read the total honestly. The blend averages probabilities, not scores — you cannot arrive at 0.42136 by weighting the three numbers above. The averaging happens per customer, then the loss is measured once.

Three models, ten families tried. Eighty-one features, seven families tried. Two hundred and eighty-one fitted models stand behind each prediction: 270 cross-validated fold fits across six fold partitions, plus 11 refits on all 24,000 rows.

Disclosure

  • Pretrained model usedTabPFN (Prior Labs), via the tabpfn package. Requires a licence and API token; performs in-context learning and fits no parameters to this dataset.
  • AI coding agent usedClaude Code, throughout.
  • External solutions consultedThe 1st, 2nd and 3rd place write-ups from the AMEX Default Prediction competition. Five techniques were tested from them — DART boosting, high min_data_in_leaf, feature_fraction_bynode, recency-window aggregates, within-customer ranks. None were adopted; all measured worse on cross-validation. The numbers are in the ledger.
  • External datasets usedNone. Only the competition-provided files.
  • Manual modification of predictionsNone beyond clipping to [1e-4, 1−1e-4].

Reproducing it

Saved prediction vectors and per-component reproduction instructions are in artifacts/. The submitted file is submissions/submission_tabpfn6.csv. A full retrain is several hours, dominated by 150 GRU fits and TabPFN’s context-length scaling.

Ensemble: 0.45 × LightGBM (81 features, 90 fits + full-data refit) + 0.30 × bidirectional GRU (6×8 panel, 150 fits + refit) + 0.25 × TabPFN (30 fits + refit, pretrained). Fixed seeds; six stratified 5-fold partitions; probabilities clipped to [1e-4, 1−1e-4] and otherwise unmodified. Out-of-fold log loss 0.42136 on 24,000 customers; 0.40982 on the 6,000-row hidden test set.
